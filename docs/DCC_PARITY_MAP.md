# ArchDisc Studio ↔ DCC Tool Parity Map

Studio's target is full **Blender** parity as the base (see
`BLENDER_KERNEL_MAP.md`) + game-engine parity (`GAME_ENGINE_PARITY_MAP.md`),
and on top of that **1:1-or-better parity** with the major DCC tools below.

This map is an **honest coverage tracker** (status as of 2026-05-29). It is the
counterpart to the other two maps for the non-Blender DCC tools, which had no
tracking before. Status legend:

- **DONE** — a real implementation exists and is verified by a headed e2e.
- **PARTIAL** — a real but limited/approximate implementation exists.
- **STUB** — a placeholder (counter / marker geometry) — not real yet.
- **ABSENT** — no implementation.

Every parity slice should cite the tool concept in code comments + ribbon
tooltips, mirror the tool's algorithm + UX, and update this table.

Integration is semi-implicit Euler with `gravity` + linear `drag` (`v *= 1 - drag*dt` after the gravity kick). `colorOverLife` is a piecewise-linear RGB gradient sampled via `sampleGradient(stops, t, out, i*3)`; `sizeOverLife` is a piecewise-linear scalar curve sampled via `sampleCurve(stops, t)` — both evaluated at `t = age / life` every tick. Determinism: a mulberry32 RNG seeded by `opts.seed` (never `Math.random`) so two emitters with the same seed produce bit-identical streams. `dt` is clamped to `[0.001, 0.1]` so a frame-skip can't teleport particles. `render.js` ships `buildParticleMesh(emitter)` → a `THREE.InstancedMesh` of a unit `PlaneGeometry`, one instance per slot, with a custom `ShaderMaterial`: the vertex shader recomposes the quad in view space using camera right/up (`mvCentre + vec3(position.x*sx, position.y*sy, 0)`) so it always faces the camera — billboard alignment without a CPU sort; per-instance `instanceColor` lives in an `InstancedBufferAttribute`; the fragment shader does soft round falloff (`smoothstep` on `dot(uv-0.5,uv-0.5)`), additive blending, depthWrite off. `updateParticleMesh(mesh, emitter)` writes positions + diagonal scale into `instanceMatrix` and RGB into `instanceColor` each frame; dead slots get `scale = 0` so they collapse out of the draw. Ops `__studioNia2Create(opts)` → `{ok, uuid, count, lifeMin, lifeMax}` / `__studioNia2Tick({uuid, dt})` → `{ok, aliveCount, particleSamples}` (first 5 live `{pos, life}`) / `__studioNia2Stop({uuid})` (resets state, RNG re-seeded, mesh stays in scene) / `__studioNia2List()` (prunes ghost handles whose mesh was removed by another path) / `__studioNia2Remove({uuid})`. Auto-registered under the `fx` palette category alongside Niagara / PFlow / MASH. Pure JS, no new deps. |
