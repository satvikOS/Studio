# Studio reference assets

Real character / reference meshes used by Studio's Archie loop when a
primitive (sphere/Suzanne) baseline can't credibly reach a portrait target.

## LeePerrySmith.glb

A clean, free human-head mesh by Lee Perry-Smith, long shipped in the
[three.js examples](https://github.com/mrdoob/three.js/tree/master/examples/models/gltf/LeePerrySmith).
Original source: <https://www.ir-ltd.net/infinite-3d-head-scan-released/>.
Bundled here as a baseline for the Video-80 photoreal-portrait build
(`e2e/studio-video80-leeperry-electron.spec.js`).
